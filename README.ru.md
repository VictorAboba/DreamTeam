# DreamTeam

[![CI](https://github.com/VictorAboba/DreamTeam/actions/workflows/ci.yml/badge.svg)](https://github.com/VictorAboba/DreamTeam/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
![Python 3.11+](https://img.shields.io/badge/python-3.11%2B-blue.svg)

**Самоорганизующийся рой ИИ-агентов без лидера.** Вы даёте рою цель, а агенты с человеческими именами
планируют её на общей доске задач, берут задачи, проверяют работу друг друга, обсуждают задачи в ветках и
личных сообщениях, делят общий git-workspace, ставят себе триггеры и сами пишут себе инструменты в виде
MCP-серверов. Сам рой тоже MCP-сервер: Claude Code может наблюдать за ним, управлять им или вступить в него
участником.

<!-- демо: здесь будет короткая GIF канбан-доски, по которой агенты двигают задачи -->

```bash
uv tool install git+https://github.com/VictorAboba/DreamTeam.git
dreamteam "Сделай игру змейка на Python с тестами"
```

## Чем отличается

- **Нет оркестратора.** Когда задана цель, на доске появляется задача планирования. Её берёт тот, кто свободен,
  остальные разбирают задачи по мере появления. Взятие задачи атомарное, зависимости блокируют, а каждую задачу
  принимает *другой* участник (независимое ревью) — или вы, если больше некому.
- **Агенты сами делают себе инструменты.** Встроенный набор инструментов небольшой: доска, сообщения, файлы,
  консоль и триггеры. Всё остальное агент пишет себе в виде MCP-сервера (`mcp_create`). Сервер проходит проверку,
  регистрируется для самого агента, для задачи или для всего роя и сохраняется в библиотеку для следующих запусков.
- **Рой — это MCP-сервер.** Подключите Claude Code (или любой MCP-клиент), чтобы действовать как пользователь:
  ставить цели, смотреть доску, принимать задачи на ревью. Или вызовите `join_swarm` и работайте внутри роя как
  участник команды.
- **Каждый шаг виден в трейсах.** Каждое пробуждение агента становится трейсом: каждый вызов LLM с мыслями,
  вызовы инструментов, токены (включая кэш), стоимость, задержка и точный контекст запроса, даже после сжатия
  истории. Трейсы можно смотреть на доске, в терминале или через MCP и выгружать в JSON.
- **Любая модель.** Claude, OpenAI, OpenRouter, Ollama, vLLM, LM Studio или любой OpenAI-совместимый эндпоинт;
  разные модели для разных агентов или ролей, учёт токенов и денег по каждому агенту и бюджет, по исчерпании
  которого рой встаёт на паузу.
- **Рассчитан на работу без присмотра.** Всё хранится в одном SQLite-файле на сессию; после перезапуска рой
  продолжает с того же места. Долгие команды не обрываются, а становятся фоновыми процессами; сессии можно
  запускать без интернета для бенчмарков, а весь рой — в песочнице Docker.

## Интерфейсы

| | |
|---|---|
| **Терминальный интерфейс** | `dreamteam` открывает интерфейс в стиле Claude Code: лента действий агентов (`⏺ Анна Смирнова · task_claim(task_id=3)`), слэш-команды, `@упоминания`, `esc` — пауза. `dreamteam -p "цель"` работает без интерфейса для скриптов и CI и выводит `text`, `json` или `stream-json`. |
| **Веб-доска** | `http://127.0.0.1:8765` — страница сессий, настройки и для каждой сессии живой канбан с перетаскиванием, ветки обсуждений задач, чат с любым агентом и лента его действий, файлы, MCP-серверы, триггеры, фоновые процессы и трейсы. Светлая и тёмная тема, русский и английский. |
| **MCP** | `/mcp` по HTTP или `dreamteam mcp` по stdio: управление сессиями и все инструменты доски, сообщений и трейсов. |
| **REST + WebSocket** | Всё, что умеет доска, — для ваших собственных инструментов. |

## Установка

Нужны Python 3.11+, [uv](https://docs.astral.sh/uv/) и git.

```bash
uv tool install git+https://github.com/VictorAboba/DreamTeam.git
```

Команда `dreamteam` появится в PATH (если она не находится, выполните `uv tool update-shell`). Чтобы менять код,
склонируйте репозиторий и установите его командой `uv tool install --editable .` — см.
[CONTRIBUTING.md](CONTRIBUTING.md) и [Установку и быстрый старт](docs/ru/getting-started.md).

## Быстрый старт

```bash
export ANTHROPIC_API_KEY=sk-ant-...        # или настройте любого провайдера в «Настройках»
dreamteam                                   # терминальный интерфейс; веб-доска тоже доступна
dreamteam "Сделай CLI для конвертации CSV в JSON с тестами"   # новая сессия с этой целью
dreamteam serve                             # только веб-доска
```

1. Откройте **«Настройки» → «Модели и эндпоинты»** на `http://127.0.0.1:8765`, выберите провайдера и модель,
   укажите ключ (имя переменной окружения или сам ключ) и нажмите **«Проверить»**.
2. На вкладке **«Сессии»** нажмите **«Начать новую сессию»** и опишите цель: первая строка станет заголовком,
   остальные — описанием. Там же можно выбрать стартовую команду, например `--team "architect, developer*2, tester"`.
3. Смотрите, как рой планирует и работает; пишите любому агенту через `@Имя`, а задачи, которые рой отдал вам на
   ревью, принимайте командой `/approve 3` или возвращайте командой `/reject 3 что исправить`. Все команды и
   клавиши: [Терминальный интерфейс и консоль](docs/ru/terminal.md).

Промпты агентов бывают на русском и английском: задайте `language = "ru"` в секции `[swarm]` файла
`~/DreamTeam/dreamteam.toml` или в окне новой сессии.

Сессию можно направить на существующий проект вместо её собственной папки — тогда агенты коммитят в вашу текущую
ветку:

```bash
git switch -c dreamteam/billing
dreamteam --workspace ~/code/my-app "Покрой модуль billing тестами"
```

Правила, которые защищают вашу собственную работу, описаны в разделе
[Папка сессии и существующий проект](docs/ru/projects.md).

### Подключение к Claude Code

```bash
claude mcp add --transport http dreamteam http://127.0.0.1:8765/mcp   # к запущенному серверу
claude mcp add dreamteam -- dreamteam mcp                               # или пусть Claude Code запустит его сам
```

Claude Code тогда действует как пользователь роя или вступает в него через `join_swarm` — см.
[Подключение к Claude Code](docs/ru/claude-code.md).

### Запуск в Docker

```bash
dreamteam sandbox ~/DreamTeam --goal "..."
```

Команды агентов и их MCP-серверы тогда выполняются внутри контейнера. Флаг `--network off` отрезает их от
интернета (строго — в Docker и на Linux), см. [Песочница Docker и сессии без интернета](docs/ru/sandbox.md).

## Конфигурация

Настройки лежат в `~/DreamTeam/dreamteam.toml`, удобнее всего их менять на странице **«Настройки»**.
Минимальный пример:

```toml
[swarm]
language = "ru"
start_agents = 3
max_agents = 8
max_cost_usd = 5.0

[models.default]
provider = "anthropic"
model = "claude-opus-5-5"
api_key_env = "ANTHROPIC_API_KEY"

[models.local]            # Ollama, vLLM, OpenRouter — любой OpenAI-совместимый API
provider = "openai"
base_url = "http://localhost:11434/v1"
model = "qwen3:32b"
api_key = "ollama"
```

Все секции и ключи: [Конфигурация](docs/ru/configuration.md).

## Безопасность

Агенты выполняют команды и код MCP-серверов **с правами вашего пользователя**. Для недоверенных целей
используйте `dreamteam sandbox`. Ключи API и другие секреты из окружения в команды агентов не передаются.
Сервер слушает `127.0.0.1` и не требует авторизации: не открывайте его в сеть без обратного прокси, который её
добавляет. Подробности: [Безопасность](docs/ru/security.md); как сообщить об уязвимости — в [SECURITY.md](SECURITY.md).
