# Скиллы

[English](../en/skills.md) · **Русский** · [Вся документация](README.md)

Скилл — это папка в формате Agent Skills от Anthropic:
`SKILL.md` с названием и описанием в заголовке YAML, инструкции и любые файлы рядом (скрипты, шаблоны, справка).
Агенты видят названия и описания подключённых скиллов при каждом пробуждении и читают `SKILL.md`, когда задача
подходит. Скиллы, написанные для Claude Code, работают как есть: их инструменты соответствуют `shell`, `read_file`,
`write_file` и `edit_file`. Сам DreamTeam ничего из скилла не запускает.

- **Библиотека** (`~/.dreamteam/skills`, `[skills] library_dir`) общая для всех сессий. В неё добавляют скиллы из
  папки, `.zip`-архива, Git-репозитория (`https://github.com/org/repo/tree/main/skills/pdf` или `URL#ветка:папка`)
  и из Claude Code: скиллы из `~/.claude/skills` предлагаются сами, а `<папка проекта>/.claude/skills` — только если
  назвать их явно (`claude-project:имя`), потому что туда могут писать агенты. Если в источнике несколько скиллов,
  нужно выбрать, какие взять. Управлять библиотекой можно на вкладке «Скиллы» стартовой страницы или через
  MCP-инструмент `skill_library`.
- **Подключение к сессии.** Скилл подключают в окне новой сессии, на вкладке «Скиллы» доски, флагом `--skill` или
  командой `/skills add` в терминале и консоли. Подключить на ходу можно и к работающей сессии: участники сразу
  получают уведомление. Через MCP скиллы передают параметром `skills=[...]` в `session_create` и `session_start`
  или подключают инструментом `skill_attach`. Копия скилла хранится в сессии, поэтому изменения в библиотеке её не
  трогают, пока вы не обновите скилл. Агенты читают копию в `.scratch/_skills/<имя>/`, а в папке проекта она
  удаляется, когда сессия уходит из неё.

  ```bash
  dreamteam --skill pdf --skill ./my-skills/review "Собери отчёт по PDF-файлам в папке docs"
  dreamteam serve --goal "..." --skill https://github.com/org/skills/tree/main/pdf
  ```

- **Роли.** У роли из каталога может быть список `skills` (`[[roles]]`): нанятый агент с этой ролью получает их
  автоматически. Если вы отключили скилл, роль не подключит его снова.
- **Предложения участников.** Агент может написать свой скилл и предложить его рою (`skill_propose`): все участники
  видят его сразу, а вас спрашивают, сохранить ли его в библиотеку (`/skills approve имя` или
  `/skills reject имя [причина]`, диалог в терминале, кнопки на доске и на карточке сессии, `skill_approve`). Решение
  можно принять и в остановленной сессии. Сессия, у которой остались нерешённые предложения, удаляется только с
  выбором: сохранить их в библиотеку или удалить вместе с сессией (диалог удаления на стартовой странице и в
  терминале, `dreamteam sessions rm ID --skills save` или `--skills discard`).
- **Зависимости скриптов.** Если в скилле есть `requirements.txt`, `pyproject.toml` (Python) или `package.json`
  (Node), пакеты ставятся автоматически при подключении в отдельное окружение для этого скилла
  (`~/.dreamteam/skill-envs`; Python через uv или pip, Node через `npm ci` / `npm install` без lifecycle-скриптов).
  Окружение общее для всех сессий с тем же скиллом и тем же набором зависимостей. Агенты получают путь к готовому
  Python, а пакеты Node находятся сами. Перед подключением видно, что будет установлено. Без манифеста агенты
  ставят то, что просит `SKILL.md`, сами. `/skills reinstall имя` переустанавливает пакеты, `/skills log имя`
  показывает журнал установки. Неиспользуемые окружения удаляются через `env_retention_days` дней (сервер проверяет
  это раз в сутки), сразу — `/skills clean-envs` или кнопка на стартовой странице. Установка пакетов запускает их код
  с вашими правами, поэтому `[skills] install = false` её отключает, а `install_proposals = false` — только для
  скиллов, которые предложили агенты.
- **Песочница Docker.** Библиотека хоста монтируется в контейнер только для чтения (источник `host-library:имя`), у
  песочницы своя библиотека в `<home>/.dreamteam/skills-library`. `~/.claude/skills` не монтируется: сначала
  добавьте такой скилл в библиотеку на хосте. Пути к папкам в песочнице — это пути контейнера, поэтому для загрузки
  удобнее zip. Node в образе нет.

```toml
[skills]
library_dir = "~/.dreamteam/skills"
claude = true             # предлагать скиллы Claude Code
max_attached = 40         # скиллов в одной сессии
max_proposals = 10        # предложений участников в одной сессии (0 — без предложений)
install = true            # ставить зависимости скриптов автоматически
install_proposals = true  # и для скиллов, предложенных агентами
env_retention_days = 30   # неиспользуемые окружения удаляются через столько дней (0 — никогда)
```
